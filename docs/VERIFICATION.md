- `pnpm test`: 2개 파일, 13개 테스트 통과.
- `pnpm build`: strict TypeScript 및 Vite 배포 빌드 통과. JavaScript 약 983KB, gzip 약 287KB. Three.js를 포함한 번들 크기 경고가 있음.
- Chromium: 장면 렌더링, 오디오 시작, 장작/마시멜로/소원/오로라, 세 번째 색 선택 제한, 소원 기록, 신원 다시 뽑기, 새로고침 후 쿨타임과 볼륨 유지 확인. 브라우저 콘솔 오류 없음.
- Chromium: resume Promise가 무기한 pending인 경우에도 오디오 복구 버튼을 즉시 표시하는 회귀 검증 통과.
- Chromium: 손상된 소원 날짜/신원/볼륨과 localStorage 접근 차단 상황에서 화면과 조작 유지 확인.
- 배포 빌드를 `/camp/` 하위 경로에서 실행하고 두 음원 로드 확인.
- 1440×1000 및 600×900 화면 캡처 확인. 불·캠퍼가 화면에 있고 액션 버튼과 왼쪽 보조 버튼이 겹치지 않음.
- 코드 리뷰 후 표현 불가능한 소원 날짜와 오디오 복구 UI 대기 문제 수정. 재검토에서 추가 중요 결함 없음.

자동 검증은 실제 스피커 청취를 대신하지 않는다. 포함 음원은 문서에서 대체 사용을 허용한 HQ MP3 미리듣기이며 원본 WAV/AIFF 인코딩과 음질 동등성을 주장하지 않는다. Headless Chromium은 실제 숨긴 탭의 제한을 재현하지 않으므로 실제 브라우저에서 백그라운드 탭 유지와 절전 복구를 별도로 확인할 필요가 있다.

- 실제 음원으로 약 278초 동안 AudioContext running 및 장작/풀벌레 양쪽 루프의 다음 회차 예약 확인. 이후 종료 콜백의 중복 호출로 같은 회차가 두 번 예약되는 문제를 발견하고, 활성 소스 Set에서 삭제에 성공한 첫 호출만 처리하도록 수정. 7초짜리 실제 AudioBuffer로 재현 시 예약 시각 `[0.15, 4.15, 8.15, 8.15]`가 수정 후 `[0.15, 4.15, 8.15]`로 바뀌는 회귀 검증 통과. 수정 후 13개 단위 테스트와 프로덕션 빌드 재통과.
