# 모바일 미디어 오디오 세션

목표: 지원하는 모바일 브라우저에서 명시적으로 시작한 불멍 소리를 미디어 playback 세션으로 재생한다.

현재 Web Audio의 기본 auto 세션을 사용한다. Audio Session API가 있으면 사용자 클릭 처리 중 AudioContext 생성/재개 전에 playback을 설정한다. dispose 또는 초기 로딩 실패 시 이전 타입으로 복구한다. 미지원/권한 거절 브라우저에서는 기존 경로를 유지한다. 3초 크로스페이드, 부스트, 저장 상태는 유지한다.

검증: 지원 API에서 playback 요청과 세션 반환, 미지원과 예외 처리 단위 테스트를 먼저 실패시킨 후 구현. FireAudio 초기 실패에서 자원 복구와 재시작 확인. 기존 13개 테스트와 빌드, Chromium 스모크 확인. iPhone 무음 스위치와 실제 화면 잠금은 실기기에서 검증해야 한다.

한계: 웹사이트는 운영체제의 강제 종료·절전 정책을 무시할 수 없다. playback API가 없는 구형 브라우저에는 네이티브 media element 재생 방식이 별도 대안이다. 브라우저 버전별 실측 없이 화면 잠금 연속 재생을 보장하지 않는다.
